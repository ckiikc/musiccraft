The icon generator uses system AppKit facilities. Fonts used by the interface are loaded from the operating system; no system font files are distributed. The framebuffer demo artwork is generated procedurally from synthetic data. No personal album cover, artist photograph, biography, lyrics, ArtCraft logo or foobar2000 asset is bundled in this source repository.
