# MusicCraft icon

Original AI-generated capuchin monkey wearing headphones, approved by the user.
The animal and headphones are strictly black and white. The background is flat,
opaque burgundy (#80283E). The square master contains no transparent pixels.

Generation: built-in image_gen, new-image mode. Prompt reference: capuchin monkey
head with headphones, black and white animal and headphones, centered ArtCraft
style silhouette, flat solid burgundy background, no gradients, reflections,
lettering or alpha holes. This is an original asset, not an official suite asset.

The macOS packager clips the master to the common suite proportions: a square
body of 824 pixels inside a 1024 pixel canvas, 100 pixel margins, corner radius
112/512 of the body (180.25 pixels). Transparency is confined to the exterior.
The master artwork and background remain unchanged.

`musiccraft-dock.png` is the same rounded macOS render, generated by `scripts/icon.swift`.
It is embedded as the eframe application icon so the running Dock tile uses the
approved artwork instead of eframe's default icon. The bundle continues to ship
the multi-resolution ICNS generated from the same master.
