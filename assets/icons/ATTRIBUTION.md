# Interface icons

Lucide icons: https://github.com/lucide-icons/lucide/tree/0.468.0/icons

New interface icons use the fixed 0.468.0 release, downloaded 2026-10-16. Settings and refresh-cw retain their existing source from main (2026-10-16). Original SVG files are included, with `currentColor` replaced by white for tinting. PNGs are rasterized at 64 × 64 with librsvg and displayed at 16–24 logical pixels. The complete upstream licenses are in LICENSE and LICENSE-0.468.0.

No foobar2000 source code, icons, screenshots or visual assets are incorporated into Aurea. The faceted navigation is an independent implementation inspired by the interaction pattern.

The arrow-down-left icon is the 180-degree counterpart of the bundled arrow-up-right Lucide icon, with the same 24-unit grid, 2-unit stroke and 64-pixel rasterization. They form the full-library/miniplayer switch pair.
